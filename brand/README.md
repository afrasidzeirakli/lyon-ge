# ბრენდი — ლოგო

აქ ჩადე ლოგო:

- logo.svg (სასურველი) ან logo.png — ღია ფონისთვის (ჰედერი)
- logo-white.svg ან logo-white.png — მუქი ფონისთვის (ჰერო, ფუტერი); თუ არ არის, ღია ვერსია გამოიყენება

`npm run dev` / `npm run build` ავტომატურად დააკოპირებს public/brand-ში.
ლოგო ადმინ პანელიდანაც აიტვირთება (პარამეტრები → ლოგო) — ადმინიდან ატვირთული უპირატესია.
სანამ ლოგო არ არის, ტექსტური ლოგოტიპი „LYON" ჩანს.
