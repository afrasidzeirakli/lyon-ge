# LYON — ფეხსაცმლის ონლაინ მაღაზია + ადმინ პანელი

ორიგინალი ბრენდული ფეხსაცმლის მაღაზიის საიტი (ქართული / English) და მისი მართვის პანელი.

**სტეკი:** Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS 4 · Prisma 6 + SQLite · Google Sans

---

## სწრაფი დაწყება

```bash
npm install
npm run setup     # Prisma კლიენტი + ბაზის შექმნა + სადემონსტრაციო მონაცემები + ფონტები/ლოგო
npm run dev       # http://localhost:3000
```

| მისამართი | რა არის |
| --- | --- |
| `http://localhost:3000` | საიტი ქართულად |
| `http://localhost:3000/en` | საიტი ინგლისურად |
| `http://localhost:3000/admin` | ადმინ პანელი |

**ადმინის საწყისი მონაცემები:** მომხმარებელი `admin`, პაროლი `lyon1234` (იცვლება `.env`-ში seed-ამდე, ან ადმინ პანელში: პარამეტრები → ადმინის პაროლი). **პირველივე შესვლისას შეცვალე.**

## რა შედის

### საიტი
- მთავარი გვერდი: ჰერო, მანიფესტი, რედაქციული სექციები, ბესტსელერები, ბენტო-გრიდი, ახალი კოლექცია, ბრენდების ზოლი, შეფასებები, კატეგორიები, ფუტერი — ყველა ტექსტი/ფოტო ადმინიდან იცვლება.
- კატალოგი ძებნით და ფილტრებით (კატეგორია, ტიპი, ბრენდი, ზომა, ფასი, ფასდაკლება/ახალი) და დალაგებით.
- პროდუქტის გვერდი: გალერეა, ფერები, ზომები მარაგით, კალათაში დამატება, **WhatsApp-ით შეკვეთა** (პროდუქტის სახელი და ზომა მესიჯში ავტომატურად ჩაჯდება).
- კალათა (ბრაუზერში ინახება) → შეკვეთის გაფორმება (სახელი, ტელეფონი, ქალაქი, მისამართი, კომენტარი, პრომო კოდი) → შეკვეთის გვერდი. გადახდა — მიწოდებისას.
- ორი ენა: `/` ქართული, `/en` ინგლისური; ენის გადამრთველი ჰედერში.
- მცურავი WhatsApp ღილაკი, ტელეფონი ჰედერში/ფუტერში.

### ადმინ პანელი (`/admin`)
- **დაშბორდი** — დღის/კვირის/თვის გაყიდვები, 14-დღიანი გრაფიკი, ტოპ პროდუქტები, ბოლო შეკვეთები, დაბალი მარაგი.
- **შეკვეთები** — სტატუსები (ახალი → დადასტურებული → გზაშია → მიწოდებული / გაუქმებული), ძებნა, WhatsApp/დარეკვა ღილაკები. გაუქმებისას მარაგი ავტომატურად ბრუნდება.
- **პროდუქტები** — ორენოვანი სახელი/აღწერა, ბრენდი, კატეგორია, ტიპი, ფასი/ფასდაკლებული ფასი, ფოტოების ატვირთვა და თანმიმდევრობა, ზომები მარაგით (სწრაფი პრესეტები), ფერები, ბეჯები (ახალი/ბესტსელერი), ჩართვა/გამორთვა.
- **კატეგორიები, ბრენდები.**
- **აქციები** (ავტომატური %-იანი ფასდაკლება ყველაზე / კატეგორიაზე / ბრენდზე / ტიპზე, ვადით) და **პრომო კოდები** (% ან ფიქსირებული, მინ. შეკვეთა, ლიმიტი, ვადა).
- **საიტის კონტენტი** — მთავარი გვერდის ყველა სექციის ტექსტი ორივე ენაზე და ფოტოები. სათაურებში `*სიტყვა*` = ნაცრისფერი აქცენტი.
- **პარამეტრები** — ტელეფონი, WhatsApp, მისამართი, სამუშაო საათები, სოც. ბმულები, მიწოდების ფასი/უფასო მიწოდების ზღვარი, Telegram შეტყობინებები, ლოგო, პაროლი.

## ფონტი (Google Sans) და ლოგო

- ფონტები **ლოკალურად** დევს `fonts/` საქაღალდეში (Google Fonts-ის ოფიციალური, OFL ლიცენზიის Google Sans და Google Sans Flex, საჭირო სიმბოლოებამდე შემცირებული — იხ. `fonts/README.md`). CDN-ზე დამოკიდებულება არ არის. Google Sans-ის ფაილს ქართული ასოებიც აქვს (მხედრული და მთავრული) და ₾-ც.
- **სათაურები OBSIDIAN-ის სტილშია:** ლათინური CAPS-ით (Google Sans Flex, წონა 900), ქართული **მთავრულით** (Google Sans, წონა 700 + GRAD 200 სისქის ღერძი). ბრაუზერები `text-transform: uppercase`-ს ქართულზე არ იყენებენ, ამიტომ ასოებს `src/lib/georgian.ts` (`toMtavruli`) ცვლის. სტილის პარამეტრები: `src/app/globals.css` → `@utility display`.
- სხვა ფაილების გამოსაყენებლად ჩააგდე ისინი `fonts/` საქაღალდეში და გაუშვი `npm run fonts` — `@font-face` წესები ავტომატურად შეიქმნება. `npm run dev`/`build` ამას თავადაც აკეთებს. თუ საქაღალდე ცარიელია, ფონტები Google Fonts-იდან ჩაიტვირთება.
- ლოგო: ტექსტური „LYON“ ლოგოტიპი (Google Sans Flex). სურვილისამებრ `brand/logo.svg` (და `brand/logo-white.svg` მუქი ფონისთვის) ან ატვირთე ადმინში (პარამეტრები → ლოგო).

## Telegram შეტყობინებები ახალ შეკვეთაზე

1. Telegram-ში **@BotFather** → `/newbot` → მიიღე ტოკენი.
2. ახალ ბოტს მიწერე რამე, შემდეგ **@userinfobot**-ისგან ან `https://api.telegram.org/bot<ტოკენი>/getUpdates`-იდან აიღე შენი chat id.
3. ადმინი → პარამეტრები → Telegram → ჩაწერე და დააჭირე „შენახვა და ტესტი“.

## დეპლოი (VPS / საკუთარი სერვერი)

SQLite ბაზა და ატვირთული ფოტოები ფაილებში ინახება, ამიტომ საიტს სჭირდება **მუდმივი დისკის მქონე სერვერი** (VPS, Hetzner, DigitalOcean, ქართული ჰოსტინგის VPS და ა.შ.). Vercel-ის მსგავს serverless პლატფორმებზე SQLite არ შეინახება — იქ Postgres-ზე გადასვლა დაგჭირდება (Prisma-ში მხოლოდ `datasource`-ის შეცვლა და მიგრაცია).

```bash
# სერვერზე (Node.js 20+)
git clone … && cd Lyon.ge
cp .env.example .env         # შეცვალე NEXT_PUBLIC_SITE_URL="https://lyon.ge" და ადმინის პაროლი
npm ci
npm run setup                # ან: npx prisma db push, თუ ბაზა უკვე გაქვს
npm run build
npm start                    # პორტი 3000; გაუშვი pm2-ით: pm2 start npm --name lyon -- start
```

წინ დააყენე nginx/Caddy reverse proxy HTTPS-ით. ბექაპი: `prisma/dev.db` და `public/uploads/`.
